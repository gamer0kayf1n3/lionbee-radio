# Lionbee Radio

The Lionbee Radio is an archived event for the Bacon's Towers of Agony Discord server. Most parts of the code and filesystem and directory structure in this repository is deliberately made to be obscure.

More documentation about the development process is available in [https://github.com/gamer0kayf1n3/lionbee-radio-puzzle](https://github.com/gamer0kayf1n3/lionbee-radio-puzzle).
